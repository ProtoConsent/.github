# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.7.x   | Yes       |
| < 0.7   | No        |

## Reporting a Vulnerability

If you discover a security vulnerability in ProtoConsent, please report it privately via email to **contact@protoconsent.org**.

Do not open a public GitHub issue for security vulnerabilities.

You can expect an initial response within 72 hours. We will work with you to understand the issue and coordinate disclosure.
